# MediaPlayer-DSA-Project
# 🎵 Java Media Player

A full-featured **Media Player** built in **Java**, supporting a wide range of audio and video formats with a clean GUI. This project was created for learning purposes and demonstrates how to integrate multimedia playback in a Java Swing-based application.

---

## 🚀 Features

✅ Play, Pause, Stop  
✅ Seek Forward / Backward  
✅ Volume Control (Increase / Decrease / Mute)  
✅ Playlist Support (Add / Remove / Clear tracks)  
✅ Support for common media formats (WAV)  
✅ Shuffle & Repeat Modes  
✅ Media Metadata Display (title, duration, current time)  




## 🛠️ Tech Stack

- **Java SE 8+**
- **Java Swing**
- **Maven**
